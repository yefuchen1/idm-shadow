改进
- BT 下载现在能接受别人连过来的连接了。以前只能主动去连别人，
  对方不主动就连不上——很多只做种不做连的冷门资源会一直卡在 0%。
  现在别人连过来我们会正经握手、发自己的 bitfield、主动要块、
  把收到的数据写到磁盘上。
- 入站连接支持 BT 协议加密握手（PE/ MSE）。现在连我们的客户端
  用不用加密都能谈拢，不用再退回到明文。
- 监听端口、路由器端口映射、DHT 宣告、tracker 上报这四处现在是
  同一个端口了。以前各报各的，别人按 tracker 上报的地址连过来
  经常连不上，或者被 NAT 挡在门外。
- 并发连接上限从 50 提到 200，候选 peer 队列提到 2000。
  这只是上限，实际连多少还取决于种子那边有多少人和你的带宽。
- 磁力链接补了一批实测能连上的 tracker 和 DHT 引导节点，
  顺便给磁力链接也用上了同一套连接配置（以前磁力链接用的
  是另一套默认配置，连接数被卡得很低）。
- 任务进度里多了 DHT 节点数，能直接看出 DHT 是通的还是全超时。

注意
- 国内网络下 DHT 基本是连不通的，实测只有两台节点能应答。
  磁力链接主要还是靠 tracker 找 peer，这一条不会因为本次更新变好。
- 这次没有加做种上传，也没有加 uTP / WebRTC 那条线路。
- 迅雷那种几百上千的连接点，靠的是它自己的私有节点和协议，
  这里的公开 tracker + DHT 规模比不了。
