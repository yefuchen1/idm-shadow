修复
- 浏览器点击下载后不再“没反应”：扩展投递失败时不再抢先取消浏览器下载，
  而是先确认 IDM Shadow 真的接住了任务。唤起应用后会等它启动完成再重试，
  始终接不住就交还给浏览器，文件不会凭空消失。
- 扩展遇到 token 过期或应用换了端口时，会自动重新读取地址和 token 再投一次，
  不再一直用旧 token 失败。
- 待确认的任务攒了几个时，最新点的那次下载仍会自动弹出保存位置对话框；
  以前会被更早的残留任务挡住，只在列表顶部提示，看着就像“没有对话框”。
- “逐个处理”现在会真的把待确认任务挨个打开。

扩展
- 扩展版本升到 0.1.2。升级后需要到 Edge 的扩展管理页重新加载一次
  `%APPDATA%\IDM Shadow\extension`，否则仍在跑旧代码。
