新增
- 磁力链接和种子文件现在会先列出里面的文件，勾选之后再下载。
  多文件种子不再默认下载全部内容——确认弹窗里能看到每个文件的大小，
  支持全选/全不选，只下你真正要的那几个。
- 没勾选的文件只做稀疏占位：磁盘上看起来有对应大小，
  实际几乎不占空间。下载过程中也不会去下这些文件的数据。
- 文件列表的抓取同时走 tracker 和 DHT，并发向多个 peer 请求，
  冷门种子拿到列表的速度比逐个试快很多。
- 种子信息会缓存成 `.torrent` 放在保存目录里，
  暂停、重启后继续下载不需要重新抓一遍文件列表。

修复
- 磁力任务在等待勾选文件时不再出现「确认了但一直不动」的状态。
  之前的实现里，确认操作和后台准备线程会互相错过，
  任务显示下载中，实际没有任何引擎在跑。
- 删除多文件种子任务时，会连同整个种子目录一起清理，
  以前对目录调用删除文件会静默失败，留下一堆残留。

注意
- 只勾选部分文件时，进度按勾选文件的总大小计算；
  分片图里未勾选的文件仍会显示为未下载，这是预期行为。
- 种子里的文件名如果包含 Windows 不允许的字符，
  会在开始下载前直接报错，不会先在磁盘上占满空间再失败。
