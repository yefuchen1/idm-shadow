修复
- 不会再自己弹出下载确认框、也不会自己开始下载了。
  以前只要浏览器里出现一个下载，IDM Shadow 就会接管它并弹出
  "选择保存位置"。有时候用户什么都没点，窗口却自己冒出来好几个——
  原因是浏览器重启时会把上次没下完的旧下载重新拉起来，
  扩展把这些旧记录当成了新下载。现在只有你亲手点过的下载才会被接管。
- 页面脚本自己发起的下载不再被接管。
  广告页、后台脚本偷偷塞的安装包，现在都老老实实交给浏览器下载，
  不再跳出来打断你。
- NAS 摄像头这类设备的封面预览图（/api/capture_image 这类地址）
  不会再被当成正式下载任务，界面上也不会多出莫名其妙的条目。
- 浏览器恢复的旧下载如果是 0 字节的，会自动清理掉，
  不会再每次开浏览器都冒出来一次。

新增
- 任务列表里每个条目都标了来源：用户点击、页面自动、浏览器恢复、
  扩展接管、手动新建……一眼就能看出哪些是误触发的。
  下载确认窗口里也会显示来源。
- 页面里的"↓ IDM"按钮改在所有窗口（包括内嵌框架）里都能正常工作。

注意
- 本次更新包含浏览器扩展的改动。更新后在扩展管理页点一次
  「重新加载」，新规则才会生效。
- 油猴脚本用户请更新脚本到最新版本，否则新的来源校验会拒绝投递。
