修复
- 扩展自动更新之后，已经打开的标签页不会再出现"点了下载一点反应都没有"。
  扩展重载之后，页面里跑着的那份旧脚本就变成了孤儿：它还拦着点击，
  但消息已经发不出去了。现在扩展会主动把旧脚本换掉。
- 浏览器要求重新加载扩展时，主界面会明确告诉你，
  而不是安静地显示成一切正常。
  以前这个状态被误判成"没问题"，用户根本不知道扩展没在跑新代码。
- 扩展升级之后的一段时间里，用户主动点的下载照常接管，
  不会因为新旧内容脚本并存而漏掉。

新增
- 主界面和下载确认窗口都能看到任务的来源，
  误接管的条目一眼就能认出来。

注意
- 本次更新包含浏览器扩展的改动。更新后在扩展管理页点一次
  「重新加载」，新规则才会生效。
- 油猴脚本用户请更新脚本到最新版本，否则新的来源校验会拒绝投递。
