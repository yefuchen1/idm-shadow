修复
- 磁力链接的任务明明在下载，状态却一直写着"排队中"。
  以前点「继续」的时候，程序会先把状态写成「排队中」，
  然后去启动任务——但磁力任务的引擎是常驻的，一直在跑，
  启动那一步就直接返回了，没人再把状态改回来。
  结果任务速度、连接数都是实的，标签却骗你说在排队。
  现在点「继续」不会再把状态写歪，正在下的东西也不会被打断。
- 刚点完「暂停」就点「继续」，点了等于没点。
  以前暂停之后引擎要花一会儿才真正停下来，
  这个空档里点「继续」会被"任务已经在跑"的判断挡掉，
  随后引擎退出又把状态写回「已暂停」。
  现在会等任务真正停下来再接着下。
- 磁力链接一个 peer 都没连上的时候，状态不再写着"下载中"。
  以前确认完保存位置之后状态会被一律改成「下载中」，
  哪怕一个连接都没有——用户看着像在下，其实在干等。
  现在这种情况有单独的状态叫「等待连接」，
  界面上和下载确认窗口都会告诉你还没连上。

改进
- 新增「等待连接」状态，磁力任务连不上 peer 时显示这个，
  不再跟"排队中""下载中"混在一起。
  排队中等的是名额，等待连接等的是资源，两回事。
- 浏览器扩展上的任务列表和图标角标也认得这个新状态了，
  等待连接的磁力任务照样算在"进行中"里。

说明
- 本次更新包含浏览器扩展的改动。
  更新后在扩展管理页点一次「重新加载」，新规则才会生效。
